For the 1.  Code and Adjacent folder:

o	The AEOLUS_MASTER_CODE file holds the Master Code for the full system to run

o	The Auxiliary Code file holds all the codes necessary to run before using the Master code
    
    o	The use is pretty self-explanatory but it is advisable to look at the Helpful Utility Codes folder which hold codes that can help move the pitch or the yaw or to test the load bank again

o	The AEOLUS_Setup_Instructions file holds the AEOLUS Setup Instructions and How to save data from the scope block instructions seen earlier in this document

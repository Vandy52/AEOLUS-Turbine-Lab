For the 5. Wind Turbine Design folder:

      o	The Aeolus Wind Turbine Design has all the files necessary to print for this iteration of the Wind Turbine in the Aeolus Wind Turbine Design folder
      
      o	To open the AEOLUS Wind Turbine design in Autodesk Fusion:
      
            o	Use AEOLUS Wind Turbine.f3z
            
                  •	To open it: 
                  
                        o	Open Autodesk Fusion 
                        
                        o	On the top left toolbar select the down arrow of File 
                        
                        o	Select Upload
                        
                        o	Either Select the file or Drag and drop the proper file into the Upload popup window
                        
                        o	Select the Upload button 
                        
                        o	Wait for the file to upload
                        
                        o	On the top right toolbar select the bell, or Notification Center
                        
                        o	In the notification that says Upload complete select Open design
                        
                        o	Make the design editable if necessary
